# ⚖️ Projeto Advocacia Premium

Protótipo de landing page premium para advocacia corporativa, desenvolvido com o objetivo de testar mecânicas complexas de animação e manipulação do DOM através do scroll.

## 🌟 Recursos do Projeto
- **Animação da Estátua:** Movimentação horizontal coordenada da esquerda para a direita conforme o usuário avança nas primeiras seções.
- **Efeito de Revelação (Masking):** A imagem de fundo da seção de contato surge gradualmente com o scroll da página.
- **Expansão Inversa da Foto:** No final do scroll, a foto de perfil se expande a partir do centro até cobrir o layout completo, fixando-se logo abaixo do menu.

## 🛠️ Tecnologias Utilizadas
- **Design & Assets:** Figma e Canva
- **Estrutura & Estilização:** HTML5, CSS3, SCSS e Bootstrap 5
- **Interatividade:** JavaScript Moderno (Vanilla JS) e Intersection Observer API
