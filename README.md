# 🚀 Jornada Frontend: Laboratório de Protótipos

Este repositório serve como meu laboratório pessoal e histórico de evolução no desenvolvimento frontend. Aqui armazeno protótipos, experimentos visuais, mecânicas de scroll, animações e landing pages completas criadas ao longo dos meus estudos e projetos práticos.

## 🛠️ Tecnologias & Ferramentas Utilizadas

### Desenvolvimento Frontend
- **HTML5:** Estruturação semântica e acessível para a web.
- **CSS3 / SCSS:** Estilização avançada utilizando Sass para organização de variáveis, aninhamentos e arquitetura modular de estilos.
- **JavaScript (Vanilla JS):** Lógica de programação, interatividade, animações dinâmicas e manipulação do DOM.
- **Bootstrap:** Framework de CSS para criação de layouts responsivos, grid system e componentes ágeis.

### Design & Prototipagem
- **Figma:** Criação de wireframes, design de interface (UI), definição de guias de estilo e protótipos de alta fidelidade antes da codificação.
- **Canva:** Criação e edição de elementos visuais, banners e assets de mídia para enriquecer as interfaces.

## 🎯 Objetivo
Registrar meu progresso técnico, testar novas bibliotecas, aplicar conceitos de design na prática e criar uma biblioteca de componentes reutilizáveis para projetos futuros.
