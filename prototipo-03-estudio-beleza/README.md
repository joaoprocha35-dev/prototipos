# 🌟 Protótipo: Studio Dalila Ruiz

Este é um protótipo de landing page de alta conversão desenvolvido sob medida para o negócio de uma colega, o **Studio Dalila Ruiz** (especializado em estética do olhar e nail design).

O objetivo principal deste projeto foi criar uma interface visualmente atraente, com estética *ultra premium*, focada na experiência do usuário (UX) e na facilidade de agendamento de serviços via WhatsApp.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** – Estruturação semântica e acessível.
* **CSS3 (Customizado)** – Estilização refinada com uso de variáveis, efeitos de gradiente e temas sofisticados.
* **Bootstrap 5** – Framework utilizado para garantir total responsividade (mobile-first) e agilidade no alinhamento de componentes.
* **JavaScript (Vanilla)** – Implementação de interações dinâmicas como:
    * Filtros dinâmicos no portfólio (Sem recarregar a página).
    * Alternância de abas no menu de procedimentos/preços.
    * Efeito de rolagem suave e fixação inteligente da barra de navegação (*Sticky Nav*).
    * Animações em cascata ativadas por scroll usando `IntersectionObserver`.

---

## 🎨 Características do Projeto

* **Design Minimalista & Luxuoso:** Paleta de cores selecionada para transmitir sofisticação, higiene e profissionalismo.
* **Filtro de Portfólio Inteligente:** Permite que a cliente navegue de forma limpa entre os trabalhos de "Sobrancelha" e "Unhas".
* **Carrossel Infinito:** Seção de feedbacks com efeito de loop contínuo para prova social.
* **Arquitetura de Conversão:** Presença de gatilhos mentais estruturados (Biossegurança, Visagismo Único) e múltiplos pontos de chamada para ação (CTA).

---

## 📁 Como Executar o Projeto

Como este é um protótipo focado em front-end estático, não há necessidade de instalar dependências complexas ou servidores robustos.

1. Baixe ou clone esta pasta para o seu computador.
2. Certifique-se de manter as imagens de referência (`foto01.png`, `unha1.png`, etc.) no mesmo diretório.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
